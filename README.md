# Anshika Srivastava | Portfolio

Personal portfolio website built with plain HTML, CSS and JavaScript. No build step or dependencies.

## Structure
```
index.html                         # the whole site (HTML, CSS, JS)
assets/profile.jpg                 # profile photo
assets/Anshika_Srivastava_Resume.pdf  # downloadable resume
```

## Run locally
Open `index.html` in a browser, or serve the folder:
```
python3 -m http.server 8000
```

## Deploy with GitHub Pages
Repo **Settings → Pages → Deploy from a branch → `main` / root**. The site goes live at
`https://anshika-srivastava-9.github.io/portfolio/`.

## Customise
- Project links: replace the GitHub profile URLs in the project cards with each repo's URL.
- Photo / resume: replace the files in `assets/` keeping the same names.
