# Anshika Srivastava — Portfolio

A personal portfolio website showcasing my projects, certifications, achievements, and journey as a Computer Science Engineering student.

🔗 **Live Site:** [portfolio-bay-ten-86.vercel.app](https://portfolio-bay-ten-86.vercel.app/)  
📦 **Repository:** [github.com/Anshika-Srivastava-9/portfolio](https://github.com/Anshika-Srivastava-9/portfolio)

---

## ✨ Features

- Clean and responsive portfolio design
- Hero section with a short introduction
- About Me section
- Projects section with GitHub repository links
- Skills and technologies section
- Certifications and achievements
- Resume section
- Direct links to GitHub and LinkedIn
- Responsive layout for different screen sizes
- Deployed and hosted using Vercel
